# Decision 0003 — Version-One Scope and Non-Goals

Status: Proposed

## Version-one features

- Open local media files.
- Drag and drop media.
- Play, pause, seek, volume, mute, speed, and fullscreen.
- Keyboard shortcuts and native application menus.
- Recent files and resume position.
- Responsive dark and light layouts.
- Accessible controls and VoiceOver support.
- Clear loading, buffering, and error states.
- Signed and notarized macOS distribution.

## Deferred features

- Video editing.
- Transcoding or format conversion.
- Cloud synchronization.
- Media-server browsing.
- Network streaming.
- Casting integrations.
- Broad third-party codec support.
- Native Swift playback replacement.

Playlists, chapters, thumbnail timelines, advanced subtitle controls, and macOS media-key integrations remain planned extension points and will be prioritized after the core player is stable.

## Definition of done

The first release is complete when a user can open a supported local video, play it smoothly, control it with mouse or keyboard, resume it later, recover from common failures, and install a signed/notarized build on a clean Mac.

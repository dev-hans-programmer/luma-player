# Decision 0001 — Product Identity

Status: Proposed

## Decision

Use **Luma Player** as the provisional product name during implementation.

Provisional technical identity:

- Application name: `Luma Player`
- Application data directory: `LumaPlayer`
- Bundle identifier: `com.example.LumaPlayer`
- Minimum macOS version: macOS 14.0+

The `com.example` bundle identifier is intentionally a placeholder and must be replaced with the real publisher-owned reverse-DNS identifier before signing or distribution.

## Rationale

The working name is short, visually compatible with a media product, and does not force the repository or architecture to depend on a final marketing decision.

## Approval required

Before Phase 1 packaging work, confirm:

- Final product name.
- Publisher/developer name.
- Real reverse-DNS bundle identifier.
- Minimum supported macOS version.
